# Weatherglass

**https://lelelilo-studios.github.io/weatherglass/**

A miniature living landscape sealed in a glass box, in the browser (three.js). Grab clouds, squeeze out rain, blow
wind, build storms, move the sun and turn the seasons.

- Grab a cloud and fling it across the sky; hold still on it to squeeze out rain, shake it hard for a storm.
- Press in the sky to condense a cloud, sweep across the land to blow, brush mist into the valley, wipe the
  condensation off the glass.
- Drag the sun (or the moon) to change the time of day; turn the season dial; press U to hide the controls.

This repository only holds the published site: one self-contained `index.html`, no build step.
